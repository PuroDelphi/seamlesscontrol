The sender and receiver must already trust each other. A receiving computer opens TCP 47833 only on its private LAN, waits for one offer, follows the approval preference, then verifies the saved file.

PREFERENCES · SAFETY

A quiet app. Full control.

SeamlessControl stays in the system tray when you close this window. Open it when you need to change computers or review a transfer.

Incoming file approval

Choose how this computer accepts files from paired computers. This applies to copied files and manual transfers.

Timed mode asks for the first file from each paired computer. After the time expires or the app exits, the setting returns to Ask every time.

Start with Windows

Launch SeamlessControl in the tray when you sign in and restore your last chosen control mode. This setting applies only to your Windows account and needs no administrator approval.

OFF

If you move the app folder, open SeamlessControl there and turn this on again to update its startup path.

Windows firewall

Allow inbound TCP for control and files, plus UDP 5353 for discovery on your private LAN. Windows will ask for administrator approval.

System tray

Closing the window hides it. Sessions started from this app continue in the tray until you stop them or exit SeamlessControl.
