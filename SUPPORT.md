# Support

[Español](SUPPORT.es.md)

Start with the [illustrated panel guide](docs/USER-GUIDE.md) for installation, pairing, connection and recovery. The [technical guide](docs/TECHNICAL.md) covers commands and the [test results](docs/TEST-RESULTS.md) show current limits.

For a reproducible problem, [open a bug report](https://github.com/PuroDelphi/seamlesscontrol/issues/new/choose). Include the Omarchy and plugin versions, whether the problem happens on the source or receiver, the panel status, the steps you took, and what happened instead. A screenshot of the panel can help. State whether both computers use the same plugin and agent revision.

Before posting, remove public IP addresses, device names, SSH keys, tokens, pairing details and private clipboard or file content from screenshots and logs. Report a security vulnerability through [the private security route](SECURITY.md), not a public issue. For conduct concerns, see the [code of conduct](CODE_OF_CONDUCT.md).

Community support is best effort; there is no guaranteed response time. Feature requests and focused pull requests are welcome through [the contribution guide](CONTRIBUTING.md).
